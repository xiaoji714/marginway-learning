# Agent Note: 安装前后的统一 Skill 入口
Status: implemented

## 为什么
外部用户应从 Skill 开始，不应先理解或安装 CLI 才能找到使用说明。

## 决策
SKILL.md 负责环境判断、安装配置与学习路由；references/usage.md 独立承载已安装后的执行契约。README 和官网短 Prompt 指向稳定 GitHub 入口，安装事实仍归安装指南。新增参考文档预算 2500 字符，避免把整个执行手册常驻加载。

## 放弃了什么
不开放私有仓库权限，不增加另一套安装器或在线执行服务；不把同一安装步骤复制进三个文档。

## 怎么验证
入口测试检查安装与操作引用，发布烟测确认独立安装后 references 仍存在；完整 CI 验证预算与打包。私有仓库仍需授权，未验证所有第三方 Agent 客户端。
