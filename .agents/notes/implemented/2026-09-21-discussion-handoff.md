# Agent Note: 讨论由 Skill 收口
Status: implemented

## 为什么
复制完整 JSON 把数据库细节和操作手册混入问题；按原文位置导出所有笔记又模糊了当前讨论焦点。

## 决策
保持 context.export 的机器数据与兼容 prompt 字段，独立格式化短交接；各字段有字符预算，超长明确标注节选；最终交接上限 2000 字符，异常历史引用超限时拒绝生成，不截断 ID。备份导入 ID 限 128 字符。复制内容只带问题、选区/当前笔记、原句、来源、稳定 ID 和 Skill 引导。Skill 按需读取讨论、当前笔记和完整语境；读写规则不重复进剪贴板。笔记 ID 保存于讨论中并校验归属和可用性；历史讨论没有 noteId 仍可读取。词汇出现记录入口保存当前词面与释义到讨论。

## 放弃了什么
不要求每个 Agent 都能访问本机，不为缩短 Prompt 引入 MCP 或自动上传资料。纯聊天使用节选并说明限制；不自动安装或保存结论。不默认复制同位置其他笔记或 AI 译文。

## 怎么验证
通过核心公共入口检查长度、长文本取回、错误关联、删除和历史兼容；扩展测试以真实资料库验证划词及笔记/词汇入口复制的焦点。完整 CI、最终 HEAD 独立评审及本机升级检查结果记录在 Issue/PR。
