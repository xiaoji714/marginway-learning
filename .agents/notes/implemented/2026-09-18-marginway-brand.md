# Agent Note: Marginway 品牌统一

Status: implemented

## 为什么

Context 容易与 Agent 上下文工程混淆。产品侧查重后，用户确认采用 Marginway · 语境，工程名 marginway-learning，并要求更宽广的副标题。

## 决策

工程、发布包、扩展名称、页面英文品牌、备份导出文件名与安装文档统一使用 Marginway。品牌副标题采用“从内容出发，让思考延续”；安装说明仍具体描述现有功能。安装器同时识别当前品牌和上一版本的扩展名称，以支持已有用户更新。

## 放弃了什么

不因品牌变化重命名 SQLite 数据目录、CLI 命令、Native Messaging 协议名称或设置存储键，避免破坏现有资料和 Agent 接口。保留上游许可证与历史技术决策，不将通用 context 代码标识符误当作品牌残留。

## 怎么验证

在新工程路径运行完整 CI，通过类型检查、42 项测试、核心四项100%覆盖率、skill校验、发布打包和独立安装烟测。产品资料与开发仓库职责分离；密钥不进入源码或发布包。
