# Agent Note: 产品 README 与演示资产

Status: implemented

## 为什么

主 README 原先更像工程说明，新用户难以快速理解语境与 Agent 延续讨论的价值，也没有可核实的产品画面。

## 决策

维持中文主 README，按定义、真实界面、学习闭环、原则、开始使用、Agent、数据流组织。安装步骤归 installation.md，测试与截图复现归 engineering.md，未来方案单独标记未实现。保留原品牌表达，准确说明私有仓库阶段、MIT 授权与外部服务边界。

新增只读本机演示入口，复用当前 common/library 构建产物，以临时 SQLite 与合成文本替换 Chrome/供应商边界。截取实际 DOM，不把演示包装页或静态释义当线上服务能力。

## 放弃了什么

不提交私人截图，不使用图像生成冒充已实现界面；不添加没有产品需求的双语 README；不增加尚不存在的商店或 Runtime 下载入口。

参考 Logseq 的价值优先、Karakeep 的定义后紧接实际截图与快速文档入口、Browser Use 的场景 Demo 与 Agent 文档分层；只借信息层次，不复制视觉与措辞。

## 怎么验证

在浏览器打开演示卡片和资料库，检查对应内容与截图；核心产品测试仍负责真实保存/恢复等行为。完整 CI 校验 TypeScript、既有回归、打包和文档预算；截图不含密钥、个人记录或浏览器 chrome。研究项的完成仅指方案，不代表未来安装器已发布。
