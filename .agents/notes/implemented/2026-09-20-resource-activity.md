# Agent Note: 资源登记与学习足迹

Status: implemented

## 为什么

YouTube 的同文档跳转可能先切换网址再更新标题。页面轮询、侧栏自动加载和后台鉴权会登记首页，造成首页资源带着旧视频名称，看起来像重复视频。统计页还缺少学习记录随日期的分布。

## 决策

后台鉴权改成只读查询，非视频页轮询不登记资源，侧栏在 YouTube 非视频页显示打开视频提示。空资源支持带版本检查的可恢复归档，有关联对象时拒绝，审计历史与备份保留；再次明确登记会恢复归档资源。不按标题推断同一资源。

activity.list 提供分页的人为创建词句语境、笔记和复习事件，保留原始 createdAt，不包含模型任务与 Agent 原生记录。学习统计是资料库默认首页，位于导航首位；全部资源保留独立入口。资料库按本地日历展示最近365天，包含闰日并避免以24小时累加导致夏令时错位；点击日期查看分类计数。编辑与重复保存不重复计数，导入保留原始日期。

## 放弃了什么

不合并不同网址，不移动任何用户笔记，不增加打卡或以观看时长推测投入。热力图是已保存学习动作的计数，不衡量学习质量；Agent 内容可在资料库查看但不计入个人学习贡献。

## 怎么验证

核心覆盖归档拒绝、恢复、历史和统计一致性，以及活动来源/分页/编辑去重。扩展测试验证切页后的只读鉴权和闰年365日历、分页、日期点击。个人空记录仅在确认无关联对象并本地备份后归档；真实数据不用于测试 fixture。
