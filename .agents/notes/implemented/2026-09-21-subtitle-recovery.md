# Agent Note: 字幕失败恢复与安装引导

Status: implemented

## 为什么

Windows 首次安装已能连接却被要求重载；特定视频 Supadata 超时与 HTTP 500 后，选中错误文字生成普通摘录，导致字幕加载误判缓存。侧栏进度刷新覆盖错误，缺少恢复入口。

## 决策

字幕缓存以 Supadata 导入来源和有效时间点识别，普通摘录仍保留在资料库。视频字幕只呈现导入字幕；界面提示不触发划词。两处失败展示中文原因、显式重试与不含密钥的诊断复制。获取与异步轮询共享 90 秒请求期限，不自动重复付费请求；保留原生字幕模式。首次安装先验证连接，只有更新文件或异常恢复时重载，并说明圆形箭头位置。

## 放弃了什么

不将 HTTP 500 归因为无字幕，不声称修复 Supadata 内部问题；不自动切换到付费转写。不清理用户已经产生的摘录或学习数据。

## 怎么验证

使用合成摘录、超时/授权/限流/500 响应验证重试和诊断；测试错误状态刷新、导航竞态及提示文字选择。现有完整 CI、覆盖率门禁与隔离 Chrome 回归，外部服务不使用真实密钥测试。
