# Agent Note: 划词卡片信息去重

Status: implemented

## 为什么

收藏结果在按钮与底部两处表达，AI 解释附带的整句译文又与语境翻译重复，来源标题占用当前素材卡片的空间。

## 决策

收藏成功由按钮勾号和已收藏状态表达，重新打开读取当前锚点的收藏记录；错误继续通过状态区提示并允许重试。选词释义只显示首行，模型要求简短纯文本且不翻译整段上下文；原文和整段翻译保留在语境区。来源标题隐藏，视频时间链接移到语境标题旁，保存记录与 Agent 上下文保留来源。

## 放弃了什么

不增加取消收藏语义或删除接口，不修改资料库来源展示，不改变保存数据格式。已有多行 AI 结果的额外解释不再挤入卡片，完整结果仍保留于任务及收藏数据。

## 怎么验证

UI 测试验证收藏成功/失败/重开、原文与翻译保留、隐藏来源标题及重复释义、时间链接和保存锚点不变；完整 CI 检查打包及独立安装。真实模型输出仍可能不遵守简短回答要求，卡片按首行显示。
