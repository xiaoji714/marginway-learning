# Agent Note: 公开前分发与安全边界

Status: implemented

## 为什么

旧静态推广页引用授权未明确的视频画面，且 docs 整体随安装包分发。安全说明缺少明确反馈入口，公开前需要核对真实可用状态。

## 决策

当前树删除旧视频图及嵌入同一视频的整体推广图，静态推广页与 README 共用已有 CC BY 视频截图，保留作者、链接、机器翻译及不背书说明。保留历史上游和图标许可。品牌版权行统一为 Marginway。

SECURITY 指向 GitHub 私密报告页；公开时启用并读回验证。不可用时只能公开请求联系渠道，不能提交漏洞细节。

## 放弃了什么

不将素材署名当成授权，不删除历史上游归属。不覆盖已发布 ZIP 或切换公开权限。经维护者明确授权后，先备份，再清理分支/标签历史中的两张旧图和作者邮箱；逐 ref 指定旧 SHA 的 lease 原子推送，短暂调整主分支规则并在 finally 中恢复和读回校验。旧 Release 撤下，以新版本重新分发；旧 Actions 安装包产物备份后清理。GitHub 保留的 PR refs 与缓存不受普通推送控制，不能宣称所有对象已擦除。维护者决定停止工单、按实际风险评估公开；补扫全部可获取 PR head 后未检出密钥或新增资料文件，残留主要是旧署名邮箱与已退出当前分发的演示图；复核确认 v0.2.3 发布提交也保留旧作者邮箱，属于本次接受的历史身份信息，不声称所有分支祖先均已匿名化。其历史可访问性和截图版权不确定性仍存在，不将规则扫描当作法律授权或零风险证明；据此不再把平台清理作为公开前置条件。

## 怎么验证

以校验过的 Gitleaks 扫描全部本地 refs 历史和已发布 ZIP 的解压目录，报告仅保留本机；另查文件类型、路径、截图与 Git 元数据。扫描无发现不代表不存在秘密或版权风险。素材引用与打包内容通过仓库检查、完整 CI 和独立评审；实际扫描结果及 GitHub API 功能状态记在对应 Issue。
