# Agent Note: 资源标题补全
Status: implemented

## 为什么
网页未加载完时，标签页可能以网址为标题。首次写入后 upsert 不更新，导致字幕完整但资源长期只有链接。

## 决策
核心只补齐自动生成的网址/空白/YouTube 通用占位标题，保留正常标题、ID、标签、关联及审计。显式编辑标题标记 titleEdited；仅编辑标签不改变现有标记。旧记录无标记时仅首次修订的占位允许补全，已修订旧记录保守保留。归档恢复可同时补全。

扩展按规范化视频 URL 请求 YouTube 公开 oEmbed，避免 SPA 残留标题串到新视频。并发共享请求，成功缓存最多 100 个视频，服务 worker 重启后清空；失败回退网址且下次注册重试。超时 5 秒，无 API Key、不调用收费服务。普通网页沿用页面标题。标题请求在页面资源授权检查后执行。

## 放弃了什么
不周期扫描整个资料库，不自动刷新已正常命名的视频，不用模型猜标题，不自动修复可能经人工编辑的旧记录。离线首次标题可能暂缺，但字幕/笔记仍可使用。

## 怎么验证
公共核心入口覆盖占位补全、标签/手动标题保护、旧数据与归档恢复；worker 真入口覆盖并发、缓存、失败重试、URL 绑定与网页路径。完整 CI、独立最终 HEAD 评审；本机两条标题取自 YouTube oEmbed 后经 CLI 带修订号更新，保持关联不变。
