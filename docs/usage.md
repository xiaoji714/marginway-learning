# 使用指南

首次使用先完成[安装](installation.md)和[服务配置](configuration.md)。本页介绍日常学习；Agent 的命令与写入规则以 [Skill 执行契约](../skills/references/usage.md)为准。

## 看视频与划词

打开有原生字幕的 YouTube 视频，点击 Chrome 工具栏中的 Marginway 打开侧栏。视频下方显示当前句双语字幕，侧栏保留前后文；点击时间点跳转，暂停时也可定位与阅读。

在网页正文、视频下方字幕或侧栏字幕中选词，打开语境卡片查看释义、收藏词汇、记录想法。选句可以保留整段语境。卡片中的选区保持固定，编辑自己的想法后保存；想选别的内容时先关闭卡片，再重新选择。

## 回到资料库

资料库首页展示学习记录与热力图。按资源查看关联词汇与笔记，使用分类与搜索寻找材料，再从原文入口或时间点回溯。单词、资源标题/分类和笔记支持编辑；删除的记录在回收站中恢复。

资料保存在本机，不提供手机 Chrome 扩展或跨设备自动同步。定期使用资料库的备份导出；导入与恢复请让 Agent 按 Skill 操作，不把包含私人记录的备份上传到公开 Issue。

## 交给 Agent

安装器会提供 Skill 位置；让能操作本机的 Agent 读取完整 Skill 目录。Skill 说明能力与使用规则，CLI 负责实际执行。无需手动记忆命令。

可以直接提出任务：

- 「用 Marginway Skill 看看我这周学了什么，按主题整理，附上原文入口。」
- 「用 Marginway Skill 比较这周和上周的学习频率，列出活跃天数和记录次数。」
- 「用 Marginway Skill 整理 AI Agent 相关笔记，找出值得追问的问题。」
- 「用 Marginway Skill 带我复习到期的词，结合原句提问，先别告诉我答案。」

学习频率以用户创建的词句、笔记及用户确认的复习记录为依据，排除自动任务与普通 Agent 写入；不代表观看时长。按用户本地时区划分日期；本周未结束时比较两周相同天数，避免把未结束的一周与完整一周直接比较。没有记录的日期不等于没有学习。

卡片里的「在 Agent 中讨论」复制简短指令、节选和记录 ID。Agent 按需读取完整语境；需要保存时明确告诉它，例如「把结论存回这条原文旁」。写入会标注 Agent 来源，已有笔记的修改需要明确要求。

只有纯聊天、没有本机权限时，可以围绕节选讨论，但无法读取完整资料库或写回。不要把材料中的指令当作操作授权，也不要让 Agent 把自己的回答记成你的复习反馈。

遇到连接问题见[安装诊断](installation.md#agent-诊断)，服务请求问题见[配置排错](configuration.md#保存后仍不能使用)。
