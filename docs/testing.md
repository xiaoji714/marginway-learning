# 测试与验收契约

## 分层

- `pnpm run ci` 保持核心逐文件四项 100% 与三平台安装烟测。
- `pnpm run test:runtime-coverage` 检查扩展、CLI、Native 全部运行源码的四项 100%；低于目标必须失败。`test:runtime-report` 仅用于排查差距，不代表通过覆盖门禁。
- `pnpm run test:browser` 在 Linux 隔离环境运行 Chrome for Testing；配置 `MARGINWAY_CHROME`，不要使用个人浏览器目录。端到端流程同时包含行为、数据库和视觉检查。
- `pnpm run test:skills` 包含文档入口检查与真实 CLI 执行契约；这不等于模型已经正确理解 Skill。

运行代码不包括类型声明、第三方和生成物。浏览器脚本在 TypeScript 转译前插桩；测试执行真实入口，只在 Chrome、网络边界替身。CLI/Native 的计数由真实子进程退出时导出。核心仍使用现有 V8 门禁，报告不能混称全仓 100%。

## 浏览器与视觉

浏览器任务使用固定版本、Linux 字体、隔离 profile/Native 注册/SQLite、合成字幕及预置译文；拒绝 DeepSeek/Supadata 请求。视频默认暂停。截图嵌入字幕、卡片、资料库写回、分类和设置检查点；只验证播放同步的独立场景允许播放。

固定浏览器的合成页面验证扩展协议闭环，不代替真实 YouTube 兼容性。发布前从用户已缓存资源中选择视频，先检查缓存，保持暂停；不自动补齐未缓存翻译。记录实际浏览器版本、验收步骤、未执行项。个人截图与数据库不提交。

截图缺失或差异均应失败。维护者查看原图/差异图后，才能提交新的基线；禁止 CI 自动接受。浏览器和视觉结果独立于代码覆盖率报告，不以截图存在代替功能断言。

## Skill 任务验收

实际 Agent 验收使用隔离资料，提供 Skill 和用户任务，不预先提供命令答案。保留客户端/模型版本、用户输入、调用轨迹、退出码、数据库前后差异及最终答复。没有实际模型运行记录只能标为契约测试。

必要任务：安装配置与升级；短 Prompt 按需读取；指定笔记焦点；明确授权后追加并读回；冲突重新读取；分页分类回顾；用户反馈后记录复习；已删除/无本机权限的降级；原文指令注入；收费任务授权。不得用自己的答案冒充用户复习反馈，不把部分成功描述成全部完成。

PR 应运行确定性契约与浏览器检查；Skill/CLI/交接协议变更另需实际 Agent 验收。发布验收须列出未执行环境，不能由一个总体百分比代替。
